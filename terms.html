利用規約 — 萬年時計

最終更新日：2026年10月4日

要点：萬年時計は無料の和暦Webアプリです。TikTok連携機能「萬年時計だより」は、運営者が個人的に運用するTikTokアカウント（@mannen_dokei）へ毎日の暦情報を自動投稿するための非商用の機能であり、第三者向けの投稿代行サービスやアカウント貸与は行いません。

1. 萬年時計について

萬年時計（mannendokei.com）は、二十四節気・七十二候・旧暦・六曜・暦注、日の出没・月相などを表示する無料の和暦Webアプリです。

2. 萬年時計だより（TikTok連携）について

「萬年時計だより」は、萬年時計が算出した当日の暦情報（六曜・日干支・旧暦・暦注・二十四節気・七十二候等）を画像とキャプションにまとめ、運営者本人が管理するTikTokアカウントに毎朝自動投稿する機能です。TikTokの Login Kit で認可を受けたアカウントに対してのみ、TikTok Content Posting API を用いて投稿します。

3. 投稿内容について

投稿される暦注・吉凶ランク等の情報は、伝統的な暦（『永代大雑書万暦大成』等を参考にしたもの）にもとづく参考情報であり、科学的な効果や結果を保証するものではありません。
