プライバシーポリシー — 萬年時計

最終更新日：2026年10月4日

要点：萬年時計（本アプリ）は、利用者の個人情報を収集・送信しません。メモや設定はすべて端末内に保存されます。TikTok連携機能「萬年時計だより」は、運営者本人のTikTokアカウントへの投稿にのみ使用し、取得した情報を第三者に提供しません。

1. 萬年時計（Webアプリ）で扱う情報

メモ、色マーク、お気に入り、誕生日、各種設定は、利用者の端末内のみに保存されます（ブラウザ／WebViewのローカルストレージ）。これらが外部サーバーへ送信されることはありません。

2. 位置情報について

日の出・日の入り等の天文計算のために「現在地」ボタンを押した場合にのみ、端末上で位置情報を利用します。位置情報を保存することはありません（都道府県の手動選択でも同じ機能を利用できます）。

3. インターネット通信について

本アプリは基本的にオフラインで動作します。以下の機能を利用したときのみ、該当する外部サービスと通信します。いずれも送信した情報が本アプリによって保存されることはありません。

  • 天気情報の取得（気圧・気温・風向）：選択中の地点の緯度経度を、気象データ提供元である Open-Meteo（open-meteo.com）に送信します。
  • 「現在地」ボタン：市区町村名を調べるため、緯度経度を OpenStreetMap（Nominatim）に送信します。

4. TikTok連携（萬年時計だより）で扱う情報

「萬年時計だより」は、萬年時計の暦情報（六曜・日干支・旧暦・暦注など）を画像にして、運営者本人が管理するTikTokアカウント（@mannen_dokei）へ毎日自動投稿する機能です。TikTokでログインして連携した場合、以下の情報を扱います。

  • TikTokから受け取る情報：Open ID、表示名、アバター画像（user.info.basic）、アクセストークンおよびリフレッシュトークン。
  • 利用目的：連携したアカウントの確認と、そのアカウントへの暦画像・キャプションの投稿（video.publish / video.upload）のみ。動画の閲覧履歴、フォロワー、メッセージ等の取得は行いません。
  • 保存場所：トークンは、投稿処理を実行する GitHub Actions の暗号化されたシークレットにのみ保存されます。ブラウザやWebサイト上には保存しません。
  • 第三者提供：取得した情報を第三者に提供・販売することはありません。広告配信、アクセス解析（トラッキング）も行いません。
  • 連携の解除：TikTokアプリの「設定とプライバシー → セキュリティと権限 → アプリの権限」から「萬年時計だより」の権限をいつでも取り消せます。取り消し後は投稿できなくなり、保存していたトークンも削除します。

5. 権限について

通知：前日リマインドや刻限通知を有効にした場合にのみ使用します。

インターネット：上記の天気情報取得・現在地の地名取得・TikTok連携にのみ使用します。

6. データの削除

アプリ内のデータ削除操作、またはブラウザのサイトデータ削除により、端末内に保存された情報はすべて削除されます。TikTok連携に関するデータの削除は、下記お問い合わせ先までご連絡ください。

7. 免責事項

本アプリの暦注・吉凶・方位などは、江戸期の暦書『永代大雑書万暦大成』等を参考にした伝統的な参考情報であり、科学的な効果を保証するものではありません。天文計算（日の出入り・月齢・節気）は独自の近似計算によるものです。
